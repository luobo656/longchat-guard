Window: 2026-10-08 through 2026-10-17 (inclusive).

## Frozen product
Extension source, manifest, permissions, user interface, core risk model, and store ZIP stay frozen at v2.1.1. Changes are limited to public website, discovery metadata, release notes, public distribution, and promotion.

## Day 1 baseline, Google Search Console (settled 2026-10-05)
- 28 complete days: 55 impressions, 1 click from page-level aggregate (query-level rows suppressed due to low volume).
- 24 tracked URLs, 6 indexed, 18 not indexed, 0 tracker errors and 0 warnings.
- Sitemap previously submitted, processing pending.
- Public Chrome store search crawler still shows an older version; publisher must check actual store dashboard and submit/approve v2.1.1 where needed.
- Metricool social publishing cannot be used until a social account is connected.

## 10-day verification metrics
- Search Console: indexed/total URLs, discovered pages, impressions, clicks, query/page winners.
- Channel work: actual external links or review submissions with URLs and pending/approved status.
- Store installs or user counts: only when dashboard data becomes available; do not invent numbers.
- GEO: test repeatable prompts for answer correctness and attributable citations; no guaranteed AI recommendation.

## Execution priorities
1. Same day: truthful three-language website first-use/onboarding CTA, verified real-site screenshots and immutable v2.1.1 GitHub Release.
2. Days 2-3: verify indexing reason for the 18 pages; improve discoverability and submit appropriate crawl requests.
3. Days 3-6: pitch or submit to relevant *curated* browser extension directories and genuinely suitable GitHub awesome lists. No mass spam.
4. Days 5-8: publish useful technical explainer or real use-case content via authorized publishing channels, localized and linked to install.
5. Days 8-10: inspect changes in impressions/indexing/distribution links, improve pages that prove effective, report wins and blockers.

## Minimal user involvement
- Confirm/submit v2.1.1 to Chrome and Edge storefronts if not yet live. We cannot infer dashboard state from cached public snippets.
- For cross-platform social posting, connect at least one social network to Metricool. Do not require this to proceed with the website/GitHub/indexing work.

Never claim a directory submission is published until an accepted, live listing is verified.
