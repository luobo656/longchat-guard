# Chrome Web Store - zh-TW

## 名稱

LongChat Guard · 長對話預警

## 簡短說明

ChatGPT 長對話預警與續接助手：一鍵讀取歷史，依據本機經驗評估風險；不提供官方額度，不上傳聊天原文。

## 詳細說明

LongChat Guard 是專為 ChatGPT 網頁版設計的長對話預警與續接助手。它利用瀏覽器本機可觀察到的對話內容，以及你確認曾達到對話長度上限的歷史記錄，提供保守、直觀的風險提醒，協助你在工作上下文變得過長之前做好續接準備。

【一鍵自動讀取】
開啟需要測量的對話，點擊「完整讀取目前對話」，即可自動載入歷史訊息，不必再手動上下捲動。開啟你親自確認曾達到長度上限的歷史對話，還可以點擊「用此對話校準」，建立本機經驗參考。自動讀取後仍須檢查訊息連續性與完整性；無法確認完整時不會儲存不可靠結果。讀取期間可隨時取消。

【清楚的風險狀態】
完成可靠校準和目前對話測量後，擴充功能會以「風險較低」「偏長」「接近風險」「高風險」等狀態與分段色帶提示趨勢。證據不足時顯示「未校準」或「暫無法判斷」，不會把未知狀態誤報為安全。

【更方便的對話續接】
點擊「複製續接提示詞」，再貼到目前的 ChatGPT 對話中，即可讓目前的模型依據它實際掌握的對話與專案上下文產生可複製的續接資料。擴充功能不會自動搬移聊天記錄，也不會代替你開啟新對話。

【隱私與權限】
首次使用前需要明確同意。聊天原文、輸入草稿、附件內容及工具結果不會以原文儲存，也不會上傳給 LongChat Guard 開發者。擴充功能在本機保存用於測量和提醒的偽匿名識別資料與經驗參考，不需要 OpenAI API 金鑰。

使用者主動執行「完整讀取」或「歷史校準」時，擴充功能會暫時使用瀏覽器偵錯權限，僅向目前前景的 ChatGPT 分頁送出模擬滾輪操作；完成或中止後會中斷偵錯連線。瀏覽器可能因這項權限顯示明顯的提示。一般對話風險監測不使用偵錯器。

【4.3.0 本次更新】
新增一鍵自動完整讀取和歷史校準；重新設計讀取過程的提示介面；改進專案中新建對話的狀態識別及長度上限提示歸屬；移除人工捲動引導、開發測試日誌和介面版本號。

LongChat Guard 是獨立開發的擴充功能，與 OpenAI 沒有隸屬或合作關係。風險提醒來自本機經驗估算，不代表 OpenAI 提供的官方權杖數量、剩餘額度或統一對話上限。

## 單一用途

為 `chatgpt.com` 長對話提供本機經驗風險提醒與續接輔助。

## 權限說明

- `storage`：儲存本機 pseudonymous 指紋、內部估算、經驗校準中繼資料、整輪增長樣本和提醒設定。
- `https://chatgpt.com/*`：只在支援的 ChatGPT 網頁端執行。

- `debugger`：僅在使用者主動開始完整讀取或歷史校準時使用，透過瀏覽器內部滑鼠滾輪事件捲動目前的 ChatGPT 分頁，並於完成、取消或失敗後解除偵錯連線。此權限本身較強，安裝警告可能涉及所有網站，但擴充功能實際操作僅限使用者主動選擇的 ChatGPT 頁面。

## 非官方聲明

LongChat Guard 是獨立開源專案，與 OpenAI 不存在隸屬、贊助、認可或維護關係。「ChatGPT」僅用於說明支援的網站和使用情境。
