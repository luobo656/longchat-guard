# Chrome Web Store - zh-CN

## 名称

LongChat Guard · 长会话预警

## 简短说明

ChatGPT 长会话预警与续接助手：一键读取历史，基于本地经验评估风险；不提供官方额度，不上传聊天正文。

## 详细说明

LongChat Guard 是专为 ChatGPT 网页版设计的长会话预警与续接助手。它利用浏览器本地可观察到的对话内容，以及你确认曾达到会话长度上限的历史记录，给出保守、直观的风险提醒，帮助你在工作上下文变得过长之前做好续接准备。

【一键自动读取】
打开需要测量的会话，点击「完整读取当前会话」即可自动加载历史消息，不必再手动上翻、下翻。打开你亲自确认曾达到长度上限的历史会话，还可以点击「用此会话校准」，建立本地经验参考。自动读取后仍须检查消息连续性与完整性；无法确认完整时不会保存不可靠结果。读取期间可随时取消。

【清晰的风险状态】
完成可靠校准和当前会话测量后，插件以「风险较低」「偏长」「接近风险」「高风险」等状态和分段色带提示趋势。证据不足时显示「未校准」或「暂无法判断」，不会把未知状态误报为安全。

【更方便的会话续接】
点击「复制续接提示词」，再粘贴到当前 ChatGPT 会话中，可让当前模型依据它实际掌握的会话与项目上下文生成可复制的续接资料。插件不会自动搬运聊天记录，也不会代替你开启新会话。

【隐私与权限】
首次使用前需要明确同意。聊天正文、输入草稿、附件内容及工具结果不会作为原文保存，也不会上传给 LongChat Guard 开发者。扩展在本地保存用于测量和提醒的伪匿名标识与参考数据，不需要 OpenAI API 密钥。

「完整读取」和「历史校准」由用户主动启动时，插件会临时使用浏览器调试权限，仅向当前前台 ChatGPT 标签页发送模拟滚轮操作；完成或中止后会断开调试连接。浏览器可能因该权限显示较明显的提示。普通会话风险监测不使用调试器。

【4.3.0 本次更新】
新增一键自动完整读取和历史校准；重新设计读取过程的提示界面；改进项目中新建会话的状态识别与长度上限提示归属；移除人工滚动引导、开发测试日志和界面版本号。

LongChat Guard 是独立开发的扩展，与 OpenAI 无隶属或合作关系。风险提醒来自本地经验估算，不代表 OpenAI 提供的官方令牌数量、剩余额度或统一会话上限。

## 单一用途

为 `chatgpt.com` 长会话提供本地经验风险提醒与续接辅助。

## 权限解释

- `storage`：保存本地 pseudonymous 指纹、内部估算、经验校准元数据、整轮增长样本和提醒设置。
- `https://chatgpt.com/*`：只在支持的 ChatGPT 网页端运行。

- `debugger`：仅在用户主动开始完整读取或历史校准时使用，通过浏览器内部鼠标滚轮事件滚动当前 ChatGPT 标签页，并在完成、取消或失败后解除调试连接。此权限本身较强，安装警告可能涉及所有网站，但插件实际操作仅限用户主动选择的 ChatGPT 页面。
