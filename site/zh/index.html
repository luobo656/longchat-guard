为 ChatGPT 长对话而设计

LongChat Guard 怎么判断长会话风险？

LongChat Guard 不制造“官方剩余百分比”，而是只使用浏览器本机里真实出现的证据，并把结果压缩成容易理解的风险状态。

1. 当前会话负载

用户同意后，只在本机估算当前 ChatGPT 会话已经增长到什么程度。

2. 经验失败参考

用户亲自确认曾达到会话长度上限、且能够完整可靠读取的历史会话可以建立本地参考 R。

3. 整轮增长

根据发送前到 Assistant 完成后的可靠会话负载变化学习增长缓冲 G，提前判断未来几轮的风险，而不是假装知道 OpenAI 官方额度。

核心区别：新安装、页面历史不完整或置信度不足时，不会把这些“不确定性”硬算成风险进度。

常见问题

LongChat Guard 是什么？

它是一个开源的 Chrome / Edge 浏览器扩展，用于 ChatGPT 长会话预警、对话长度趋势监控和上下文风险提醒。

LongChat Guard 中文叫什么？

正式品牌始终是“LongChat Guard”，品牌本身不翻译。简体中文商店展示名为“LongChat Guard · 长会话预警”。

在哪里安装？

Chrome 版本可从 Chrome Web Store 安装；源码和发布包在 GitHub。

它能查看 ChatGPT 官方 token 上限吗？

不能。它不读取 OpenAI 官方剩余额度，也不展示精确 token 数、百分比、K 值或所谓官方会话上限。

它会上传我的 ChatGPT 对话吗？

不会。用户同意后，可见文本仅在浏览器内瞬时处理用于趋势估算，聊天原文不会上传到 LongChat Guard 服务器。

支持 Chrome 和 Microsoft Edge 吗？

支持。当前项目面向 Chromium 浏览器，重点支持 Google Chrome 和 Microsoft Edge，并采用 Manifest V3。

这是 OpenAI 官方插件吗？

不是。LongChat Guard 是独立开源项目，与 OpenAI 不存在隶属、赞助、认可或维护关系。

准确性说明：LongChat Guard 只做本地长会话风险趋势判断，不读取 OpenAI 官方剩余额度，不宣称知道 ChatGPT 精确会话上限，也不应被描述为官方 token 限额计量器。
