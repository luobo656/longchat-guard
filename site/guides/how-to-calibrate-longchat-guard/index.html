How to set up LongChat Guard's automatic reading and risk alerts

LongChat Guard cannot see an official ChatGPT token allowance. It estimates conversation risk locally, so reliable warnings require both a usable current-chat measurement and a historical conversation that you personally know reached the length limit.

Quick answer: Install and consent, open a genuinely limit-reached historical conversation, choose the calibration action, keep ChatGPT in the foreground while automatic reading checks both ends, then return to your current chat. A normal long chat is not proof of a limit.

Updated October 22, 2026

Before you calibrate: choose the right conversation

Use a historical ChatGPT thread that you personally observed hitting a conversation-length limit. An ordinary long conversation, a slow-loading page, a file upload failure, or a temporary rate limit is not equivalent evidence. If you have no confirmed failure sample yet, continue using ChatGPT normally; LongChat Guard will show Not calibrated rather than invent a threshold.

Step-by-step setup

1. Install and consent

Install LongChat Guard, open chatgpt.com, and review its local-processing disclosure. It does not require an OpenAI API key or a LongChat Guard account.

2. Open your confirmed limit-reached chat

On that historical page, use the calibration action: the “Calibrate with this chat” option when a genuine limit notice is detected, or the menu action to relearn the reminder baseline.

3. Let the automatic read finish

Keep this ChatGPT tab active. Browser-internal wheel input loads older messages and returns to the newest message; the original scanner then checks continuity. You can cancel; incomplete evidence is not saved.

Once a compatible reference exists and the current chat has been measured reliably, the extension can show risk states. A completed historical read alone does not guarantee an authoritative OpenAI limit.

Full current-chat reading is different from calibration

Read full current chat measures the conversation you are viewing (current load, L). Calibrate with a confirmed historical limit establishes the failure reference (R). Reading an ongoing chat should not silently replace R. Both actions use the same automatic scrolling preparation and the same message measurement rules.

Why that distinction matters: using a chat that has not actually failed as your limit reference would make the risk track misleading.

What the status messages mean

Not calibrated

No compatible, confirmed historical failure reference is currently available. Wait for genuine evidence rather than treating a long chat as a limit.

Unable to assess

Current chat coverage, message ordering, or the measurement environment cannot be verified. In a long historical chat you can request a full automatic read and try again.

Lower / Long / Near / High risk

These are estimated positions relative to your local reference and observed conversation growth—not exact token percentages or official remaining quotas.

Why does the browser show a debugger permission?

The optional user-started full read uses the browser's powerful debugger permission to send simulated mouse-wheel input to the active ChatGPT tab. LongChat Guard detaches when the operation finishes, is cancelled, or fails. Normal passive risk monitoring does not use this permission. Its underlying browser permission is broader than the extension's self-imposed active-tab restriction, so a strong browser warning is expected.

Chat text is read transiently by the website content script for local measurement, not by the debugger, and is not uploaded to a developer analysis server. See the privacy policy.

When should I start a fresh ChatGPT conversation?

When the locally estimated risk becomes meaningful, ask your current ChatGPT conversation to prepare a handoff. Carry forward the goal, confirmed decisions, constraints, relevant file/code state, unresolved issues, and next actions; verify the key facts in the new conversation. The extension provides a continuation prompt, not an automatic transfer.

Neither the warning nor the handoff implies an official OpenAI capacity number.

Quick troubleshooting

Do I need to scroll manually?

No. The 4.3.0 reading flow is automatic. Keep the tab in front, do not interact during reading, and use Cancel if needed.

Can I calibrate before any chat reaches its limit?

No trustworthy historical failure reference is available in that situation. Continue using the extension, and establish the reference only after a confirmed length-limit event.

Will the tool tell me exactly how many tokens remain?

No. Its internal load units are not official OpenAI token counts, and it does not promise one universal ChatGPT limit.
