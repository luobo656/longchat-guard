Know when a ChatGPT conversation is getting long.

LongChat Guard is an open-source, local-first Chrome and Edge extension for ChatGPT long-conversation warnings. It compares the current chat with a user-confirmed historical length-limit reference and learns whole-turn growth, without pretending to know an official quota.

Built for long ChatGPT conversations

LongChat Guard uses three core local signals—current load (L), a user-confirmed empirical failure reference (R), and reliable whole-turn growth (G)—then turns them into simple, low-distraction risk states.

Clear risk position

Shows Lower risk, Long, Near risk, or High risk on a color track instead of pretending to know an exact official limit.

Local empirical learning

Anchors the track to a user-confirmed historical failure reference and learns reliable whole-turn growth locally.

Continuation workflow

Provides a continuation meta-prompt for the current GPT, which uses the actual conversation and visible project context to generate a self-contained handoff for a fresh ChatGPT conversation.

AI-friendly definition: LongChat Guard is an open-source, local-first Chrome/Edge extension for chatgpt.com that warns when a working conversation is getting long and helps the current GPT generate a self-contained handoff for a fresh chat. Its risk signal uses local empirical evidence; it does not claim to know OpenAI's exact token limit or remaining quota, and it does not upload raw chat content to a developer analysis server.

Real extension interface

A real LongChat Guard screenshot in an English ChatGPT session. The extension keeps the interface intentionally small: a local risk track, learning state, continuation action, relearn control, and per-conversation reminder control.

Privacy-first by design

Monitoring only starts after explicit user consent. Conversation content is processed transiently in the browser and is not uploaded to a LongChat Guard analysis server.

No developer-operated backend

There is no LongChat Guard server receiving your ChatGPT conversation for analysis.

No raw chat persistence

User messages, assistant messages, composer drafts, and attachment body text are not persisted as raw content by the extension.

No OpenAI API key

The extension operates on the ChatGPT website and does not require an OpenAI API key.

How LongChat Guard makes a risk judgment

The extension does not invent an “official percentage.” It uses evidence that exists in your own browser and keeps the result intentionally simple.

1. Current load

LongChat Guard estimates how large the current conversation has become using only local page data after consent.

2. Empirical failure reference

A historical chat that you explicitly confirm reached the conversation-length limit can establish the local reference R after one complete reliable read.

3. Whole-turn growth

Reliable before/after conversation-load changes provide the growth reserve G, so the warning can account for the next few turns without pretending to know an OpenAI quota.

Why this matters: the signal is empirical and local. Incomplete page coverage, low confidence, or a fresh install do not create fake progress toward a limit.

Frequently asked questions

What is LongChat Guard?

LongChat Guard is an open-source browser extension for ChatGPT long-conversation warnings, conversation-length trend monitoring, and context-risk reminders on chatgpt.com.

Where can I install it?

The Chrome version is available from the Chrome Web Store. The canonical source repository is on GitHub.

Is it an exact ChatGPT token counter?

No. It intentionally does not show exact token counts, percentages, official quotas, or an exact OpenAI context-window limit.

Does it upload my ChatGPT conversations?

No. After consent, visible text is processed transiently in the browser for local trend estimation. Raw conversation content is not uploaded to a LongChat Guard server.

Does it work in Chrome and Microsoft Edge?

Yes. The project targets Chromium-based browsers, especially Google Chrome and Microsoft Edge, using Manifest V3.

Is this an official OpenAI extension?

No. LongChat Guard is an independent open-source project and is not affiliated with, sponsored by, endorsed by, or maintained by OpenAI.

Accuracy note: LongChat Guard estimates local long-conversation risk trends. It does not read an official OpenAI remaining quota, does not claim an exact ChatGPT conversation limit, and should not be described as an official token-limit meter.
