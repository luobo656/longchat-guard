在 ChatGPT 對話變得太長之前，提早知道。

LongChat Guard · 長對話預警 是一個開源、本機優先的 Chrome / Edge 擴充功能。它把目前本機可測對話負載與使用者親自確認曾達到長度上限的歷史參考做比較，並學習可靠的整輪增長，協助你在適當時機整理或開啟新對話。

專為長 ChatGPT 對話設計

核心使用三個本機信號：目前負載 L、使用者確認的經驗失敗參考 R、可靠的整輪增長 G。

清楚的風險位置

用彩色軌道顯示風險較低、偏長、接近風險、高風險，不把本機估算冒充成官方精確上限。

本機經驗學習

用使用者確認的歷史失敗對話建立本機參考，並從可靠的整輪對話變化中學習增長緩衝。

三步使用 LongChat Guard

剛安裝後顯示「未校準」或「暫無法判斷」是正常情況。擴充功能不會把未知風險誤當成安全。

1. 安裝並同意本機監測

在 chatgpt.com 頁面同意使用本機可見資料；不需要額外帳號或 OpenAI API Key。

2. 用真正達到上限的歷史對話校準

開啟你確定曾達到對話長度上限的歷史對話，選擇「用此對話校準」。掃描不完整時不會建立有效參考。

3. 依風險適時續接

測量和校準都可靠後才顯示經驗風險；需要新對話時，讓目前 GPT 產生自包含的續接內容。

常見問題

LongChat Guard 中文名稱是什麼？

正式品牌始終是 LongChat Guard，不翻譯成其他品牌名。繁體中文商店展示名為「LongChat Guard · 長對話預警」。

它能查看 ChatGPT 官方 token 上限嗎？

不能。它不讀取 OpenAI 官方剩餘額度，也不顯示精確 token、百分比或所謂官方對話上限。

它會上傳我的 ChatGPT 對話嗎？

不會。使用者同意後，可見文字只在瀏覽器內暫時處理；聊天原文不會上傳到 LongChat Guard 伺服器。

這是 OpenAI 官方擴充功能嗎？

不是。LongChat Guard 是獨立開源專案，與 OpenAI 不存在隸屬、贊助、認可或維護關係。
