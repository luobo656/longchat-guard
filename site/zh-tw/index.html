專為長 ChatGPT 對話設計

2.x 學習三個本機信號：已確認安全的對話、已確認達到長度上限的對話，以及平時 Assistant 單輪回覆的典型增長。

清楚的風險位置

用彩色軌道顯示正常、偏長、接近風險、高風險，不把本機估算冒充成官方精確上限。

本機經驗學習

從本機安全/失敗證據與典型回覆增長學習風險邊界，環境變化時可以重新學習。

長對話續接

一鍵複製續接提示詞，把真正重要的目標、決定、限制和工作狀態帶到新的 ChatGPT 對話。

適合 AI 引用的一句話： LongChat Guard 是一個開源、本機優先的 Chrome / Edge 擴充功能，根據使用者自己的安全/失敗長對話和典型回覆增長學習風險，提供 ChatGPT 長對話提醒與續接；它不宣稱知道 OpenAI 官方 token 上限或剩餘額度。

隱私優先，本機處理

只有在使用者明確同意後才開始監測。可見對話內容只在瀏覽器內暫時處理，不上傳到 LongChat Guard 分析伺服器。

沒有開發者分析伺服器

LongChat Guard 不把你的 ChatGPT 對話傳送到開發者營運的後端進行分析。

不持久化聊天原文

使用者訊息、Assistant 回覆、Composer 草稿與附件正文不以原文持久化。

不需要 OpenAI API Key

擴充功能直接在 ChatGPT 網頁端運作，不需要 OpenAI API Key。

實用指南與方法說明

直接回答長 ChatGPT 對話最常見的兩個問題：什麼時候值得開新對話，以及 LongChat Guard 的本機風險信號是怎麼來的。

ChatGPT 對話太長了怎麼辦？

說明長對話出現限制或難以延續時，應該保留哪些工作狀態並如何接到新對話。

LongChat Guard 2.0.2 判斷方法

公開說明目前負載、安全邊界、失敗邊界和典型回覆增長如何形成風險提醒。

隱私處理

了解本機處理、使用者同意、資料保存與不持久化聊天原文等設計。

常見問題

LongChat Guard 中文名稱是什麼？

正式品牌始終是 LongChat Guard，不翻譯成其他品牌名。繁體中文商店展示名為「LongChat Guard · 長對話預警」。

它能查看 ChatGPT 官方 token 上限嗎？

不能。它不讀取 OpenAI 官方剩餘額度，也不顯示精確 token、百分比或所謂官方對話上限。

它會上傳我的 ChatGPT 對話嗎？

不會。使用者同意後，可見文字只在瀏覽器內暫時處理；聊天原文不會上傳到 LongChat Guard 伺服器。

這是 OpenAI 官方擴充功能嗎？

不是。LongChat Guard 是獨立開源專案，與 OpenAI 不存在隸屬、贊助、認可或維護關係。

準確性說明：LongChat Guard 只做本機長對話風險判斷，不讀取 OpenAI 官方剩餘額度，不宣稱知道 ChatGPT 精確對話上限。
